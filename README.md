# FiiO M21 / JM21 device research

Public notes on FiiO's M21 and JM21 Android audio players: community research, safe-to-share device documentation, and a documented screen wake flicker investigation.

> **Model names matter:** FiiO M21 and JM21 are different products. This collection includes references to both, and labels which model each report concerns. The investigated unit is a **FiiO JM21**.

## Contents

- [JM21 screen flicker on wake](display-wake-flicker/README.md): observations, restoration tests, log summary and next checks.
- [Community reports](display-wake-flicker/community-cases.md): related user reports, with their limits.
- [M21 BaseOS research index](m21-baseos/README.md): short index to the existing M21 BaseOS assessment project.
- [Sources](SOURCES.md): official and technical references.

## What is included

Original notes and links that may help other owners investigate similar symptoms. Reports from forums are anecdotal and do not establish a common cause.

Raw device logs, partition images, calibration/identity data, firmware packages, extracted proprietary binaries, APK collections, private paths and account/network identifiers are intentionally excluded. Do not use this repository as a firmware download or flashing guide.
