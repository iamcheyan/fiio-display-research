# M21 BaseOS research

The local research collection contains a separate assessment of porting BaseOS/PocketJS to the FiiO M21. This public repository currently provides an index only; it does not redistribute firmware, partition images, APKs, source snapshots, or device backups.

Keep **M21** and **JM21** findings separate. Hardware, firmware and partition details from one model should not be assumed to apply to the other.

For the existing public project, see [m21-baseos-assessment](https://github.com/iamcheyan/m21-baseos-assessment).
